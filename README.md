# Sleek Steps

Crie um e-commerce premium, moderno e minimalista para uma marca especializada exclusivamente na venda de tênis.

O objetivo é transmitir sofisticação, exclusividade e tecnologia, inspirando-se em marcas como Nike, New Balance, Adidas Confirmed, Axel Arigato e Salomon.

Não gere imagens de produtos.

Utilize apenas placeholders escuros para todas as imagens, deixando espaços bem definidos para que elas sejam adicionadas posteriormente.

Objetivo Final

O resultado deve parecer o site de uma marca de sneakers de alto padrão, com forte apelo visual e foco total na apresentação dos produtos. A interface deve utilizar fundo escuro texturizado, detalhes em mostarda, tipografia marcante e muito espaço em branco para transmitir sofisticação. Em vez de exibir muitos produtos por seção, mostrar apenas dois cards grandes e complementar cada área com um bloco de chamada para ação ("Ver coleção completa" ou "Descobrir lançamentos"), acompanhado de uma seta animada que incentive a navegação. Todas as imagens devem ser representadas por placeholders elegantes, mantendo o layout pronto para receber fotografias reais posteriormente. O checkout não será implementado; a compra será direcionada ao WhatsApp. O projeto deve ser organizado de forma modular, preparado para futuras expansões sem necessidade de reestruturação.
